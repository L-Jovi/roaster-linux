# Security

These are personal Linux learning notes and small scripts, not maintained software.
The maintained branch is `master`; there are no supported releases or response-time
promises. Review any script before running it, and never run it with real secrets
pasted into the source.

Report sensitive vulnerabilities through GitHub's private vulnerability reporting
(**Security → Report a vulnerability**) on this repository. Use a public issue for
ordinary bugs without security impact. Include the affected file, commit and
reproduction steps, without real credentials.
